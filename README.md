# About

BlakApp is a program that allows you to find and analyze peptides. 

App contains three tools:
1. Peptide searcher from RNA/DNA code

2. Peptide drawing tool 
Shows you how does peptide look like

3. Peptide analyzer
Shows you certain peptide properties such as:
- Mass
- Izoelectric point
- Extinction Coefficient
- Net Charge
- Hydrophobicity
- Polar and non-polar codons
